# 圖片處理小工具集

一系列單檔 HTML 的圖片小工具。每個工具都只有一個 `.html` 檔案，下載下來用瀏覽器打開就能用，不需要安裝軟體、不需要網路、不需要註冊帳號。

**圖片完全在你自己的瀏覽器裡處理，不會上傳到任何伺服器。**

## 工具列表

| 工具 | 說明 |
| --- | --- |
| [圖片對半切.html](圖片對半切.html) | 把圖片切成上下兩半和左右兩半，一次產出 4 個檔案 |

## 下載與開啟

點上面表格裡的檔名進入檔案頁面，按右上角的下載按鈕（Download raw file，向下箭頭圖示），檔案就會存到你的電腦。也可以按這個倉庫綠色的「Code」按鈕，選「Download ZIP」，一次下載全部工具。

下載後直接雙擊檔案，或拖進 Chrome、Edge、Safari、Firefox 任一個瀏覽器視窗就會打開。

## 圖片對半切

把一張圖切成兩半，同時產出兩種切法，共 4 個檔案：

| 檔名後綴 | 切法 | 內容 |
| --- | --- | --- |
| 水平切1 | 用水平線切開 | 上半 |
| 水平切2 | 用水平線切開 | 下半 |
| 垂直切1 | 用垂直線切開 | 左半 |
| 垂直切2 | 用垂直線切開 | 右半 |

**放入圖片。** 把圖片拖進虛線框、點一下虛線框選擇檔案，或直接按 Ctrl+V（Mac 是 Cmd+V）貼上剪貼簿裡的圖片。可以一次放很多張。支援 JPG、PNG、WebP、GIF（只取第一格）等瀏覽器看得懂的格式。

**選擇輸出格式。** PNG 是無損格式，會保留透明背景。JPG 檔案比較小，可以拉動「品質」滑桿調整（預設 92）；JPG 不支援透明，透明的地方會補成白色。

**檔名。** 輸出檔名是「原檔名＋後綴」，例如 `photo水平切1.png`。勾選「檔名與後綴之間加底線」會變成 `photo_水平切1.png`。

**下載。** 每一格都有自己的「下載」按鈕；也可以按「下載這張的 4 個檔案」，或最下面的「全部下載」一次下載所有圖片。第一次連續下載時，瀏覽器可能會詢問是否允許下載多個檔案，請按允許。

圖片寬或高是奇數像素時，多出來的 1 像素會分給第 2 半（下半或右半），兩半拼回去剛好等於原圖，不會少掉任何像素。
